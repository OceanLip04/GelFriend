# 三框泳道修复 · 2.2.1

日期：2026-10-15。

旧实现使用 round(首末跨度 / 首两条间距) 决定间隔数，并拒绝分数差大于 0.25 的参考框。末框落在两个推断位置之间时，即使手画符合实验图，也被要求重画。

新实现保留顺序、共同高度、边界与数量上限校验，去掉分数差硬拦截。首两框只推算数量；首末中心决定最终等距排列。用户可覆盖总数 3–200，首次估算不确定时明确提示核对。宽框按实际间距收窄，不要求反复重画。

画完三个参考框后显示青色虚线预览，数量输入与加减立即刷新，尚不替换任何已有泳道或条带。确认使用后才替换；已有泳道存在时说明替换范围。修改数量、单个参考框或倾角会重新启用预览。生成后沿用原有拖框与删除操作。

手动数量与确认状态随项目保存；新图清空，旋转导致参考框重选时清除旧预览。原始像素与积分算法未修改。

另修复“关于胶个朋友”将 NSAlert 附着在隐藏旧窗口的错误。关于及错误提示附着当前分析工作区，关于版本号读取 Bundle，弹窗关闭不切换工作区。隐藏旧窗口仍用于现有批量/导出后端。

35 项原始图像/旋转/批量、47 项分析核心、13 项倾斜几何、30 项工作区与 24 项实验流程，共 149 项通过。新增覆盖分数间距边界、手动数量、宽框收窄、无效数量修正、预览不修改现有几何、原始像素不变、项目保存与旋转清除。

原生 WKWebView 已验证旧版会拒绝的参考跨度/首两间距比为 3.5 的项目显示五条青色虚线，点加号变成六条，点使用后出现六条可编辑泳道与样本清单。原生菜单验证“关于胶个朋友”显示 2.2.1 的轻量弹窗，点击“好”回到打开前的实验首页，未出现旧 SGD 查看界面。

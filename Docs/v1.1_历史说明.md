# GelScope · SGD 胶图查看器 1.1

中文 Mac 桌面应用，已用 `20261012Promoter.sgd` 实测。运行需要 Apple 芯片（M1/M2/M3/M4 等）和 macOS 13 或更新系统，不需要安装 Python 或第三方图像库。

## 打开使用

1. 双击 `dist/SGD胶图查看器-v1.1.app`，也可以将它复制到“应用程序”文件夹。
2. 点击“打开胶图…”选择 `.sgd` 文件，或将文件拖入胶图区域。也可以在 Finder 的“打开方式”中选择本程序。
3. 使用“适应窗口”、100%、加减按钮缩放；放大后可用滚动条或触控板移动。
4. 右侧可以设置黑场、白场、Gamma、反相和上下翻转。
5. 上方“旋转”栏提供左转 / 右转 90°、角度滑块、角度输入和归零；角度支持两位小数，正数顺时针，负数逆时针。

## 新增：自由旋转和批量处理

自由旋转会扩大画布以容纳完整胶图。90° 的整数倍直接重排像素；其他角度对预览使用双线性插值，空白区域为黑色，反相时为白色。旋转效果包含在 PNG 中，原始 16 位 TIFF 保留采集像素的存储方向。

1. 点击“批量处理…”，按住 Command 多选 SGD 文件；也可以在“文件”菜单中使用批量处理。
2. 默认同时导出 **PNG + 原始 16 位 TIFF**，也可只选其中一种。
3. PNG 可以为每张胶图分别计算自动对比度、使用各自完整像素范围，或沿用当前打开胶图的黑场与白场。Gamma、反相和上下翻转沿用当前设置；批量旋转角度可在面板中修改。
4. 选择导出文件夹，点击“开始批量导出”。程序在该位置新建带时间的子文件夹。
5. 处理结束后显示成功 / 失败 / 取消的文件数量，点击“查看导出结果”打开结果文件夹。

同名输入文件会获得不同的导出文件名；已有结果不覆盖。单个文件失败时继续处理其余文件，并在 `处理结果.csv` 中记录错误、输出文件和 PNG 的显示参数。点击“停止处理”会在当前文件完成后停止，保留已完成的输出与处理记录。

## 界面与图标

暖白纸色背景、陶土色控件与衬线标题，图标融合 DNA 双螺旋和三泳道凝胶条带。图标已打包进应用，原图和 macOS 图标位于 `Assets/AppIcon-1024.png` 与 `Assets/AppIcon.icns`。生成工具与完整提示词见 `Assets/图标生成说明.md`。

若文件位于微信等应用的容器或受系统保护的位置，请通过“打开胶图…”选择该文件，让 macOS 授予对此文件的访问。命令行传入的路径可能需要先在文件选择器中打开一次。

## 显示与导出

- 打开文件时自动使用 0.5%–99.5% 分位点提高显示对比度；这可能与 GeneSnap 保存的显示效果不同。
- 黑场以下显示为黑色，白场以上显示为白色；Gamma 大于 1 时中间灰度变亮。
- “重置”恢复最小值至最大值的线性显示、Gamma 1、原始方向和不反相；“自动对比度”重新计算灰度范围。
- **导出 PNG**：8 位灰度，包含当前的显示调整、旋转和上下翻转，用于查看或排版。
- **原始 TIFF**：16 位灰度，保留原始像素值和存储方向，不应用显示调整，不把样例的 0–4095 数值扩展为 0–65535。采集记录和厂商审计信息不包含在 TIFF 中。
- 软件只读 `.sgd`，不向原文件写入数据；导出使用单独的文件名。

## 兼容范围

当前支持 CFB 复合文档中的 `Detector/GeneSnap/RawData/PixelData`，像素头为版本 1、单通道 16 位小端编码（已验证样例的字段序列为 `1, 1, 1, 4`）。CFB 读取器支持普通扇区、小扇区和扩展 DIFAT。

已验证的成像软件版本为 **GeneSnap 7.09.17**。不能据此保证所有 `.sgd` 文件兼容。其他像素编码、彩色/多通道、复合曝光或其他厂商同扩展名文件尚未支持；不能解码时会显示明确错误。

显示原始胶图，不重建 GeneSnap 的处理后图层、文字标注、测量结果或已保存的显示参数；不验证厂商 GLP 审计信息。当前文件大小上限为 256 MB、像素数上限为 5000 万。

| 图像尺寸 | 1392 × 1040 |

1.1 的 35 项自动检查通过，覆盖已知像素的合成文件、参考像素校验、小文件流、灰度映射、Gamma、反相、翻转、自由旋转、PNG/TIFF 往返、损坏文件拒绝、批量双格式导出、同名文件、失败继续处理、参数记录、独立输出目录和取消。另实测暖色窗口、图标与自由角度旋转。参考测试文件位于 `Tests/Fixtures/retained-pixels-test.sgd`，其采集文本明确注明测试用途。

原始像素字节 SHA-256：`9095d2f4fb0d3e0f60408ee25a8ee8628edaf673f42e415921f621a7c0c1097a`。

`inspection/20261012Promoter_preview.png` 和 `inspection/20261012Promoter_raw16.tif` 是本次样例导出结果；`inspection/gui_export.png` 是从界面导出的验证结果。

## 源码与构建

源码在 `Sources/`。使用 macOS 自带的 AppKit、CoreGraphics、ImageIO 和 Foundation，构建需要 Xcode 命令行工具中的 Swift 编译器。

```sh
./build.command
./test.command Tests/Fixtures/retained-pixels-test.sgd
```

本次发布包为 `dist/SGD胶图查看器-v1.1.app` 和 `dist/SGD胶图查看器-v1.1-Mac.zip`。构建脚本默认输出 `dist/SGD胶图查看器.app`；使用 `SGD_APP_NAME=SGD胶图查看器-v1.1 ./build.command` 可生成版本化文件名。应用采用本地临时签名，未进行 Apple 开发者公证。

可选命令行功能：

```sh
'dist/SGD胶图查看器.app/Contents/MacOS/SGDViewer' --inspect '/路径/胶图.sgd'
'dist/SGD胶图查看器.app/Contents/MacOS/SGDViewer' --export-original '/路径/胶图.sgd' '/路径/原始.tif'
'dist/SGD胶图查看器.app/Contents/MacOS/SGDViewer' --export-preview '/路径/胶图.sgd' '/路径/预览.png'
```

命令行预览采用自动对比度、Gamma 1 和原始方向。原始 SGD 不包含在应用 ZIP 中；查看和导出均在本机执行。

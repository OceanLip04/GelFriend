## 数据与单位

SGD 由 Swift 读取 CFB 结构和已识别的原始像素流。16 位存储不意味着采集有效满量程为 65535；用户参考胶图的值域为 0–4095。PNG 预览不能作为原始定量数据，原始 TIFF 导出不应用旋转或显示拉伸。

FCS 严格按 DATATYPE、BYTEORD、各 PnB 和 TOT 解码；支持整数 8/16/24/32、float32、float64。TEXT 定界符支持双写转义。DATA 区长度至少应满足事件数 × 步长，真实样例允许声明结束偏移恰好等于 EOF 的一字节偏差，同时记录警告。不将 PnR 当作掩码截断数据，不对存储单位按 PnG 任意重缩放。当前拒绝 PnE 对数编码、NEXTDATA 多数据集及非 List 模式，避免错误猜测。

文件 SHA-256 标记输入文件；DATA 哈希标记原 DATA 字节；valuesHash 标记分析项目嵌入的 float64le 数值字节。派生参数 / VCP 的 valuesHash 重算，原文件哈希及来源映射保留。打开项目核对数值哈希并从事件重算所有门。

## 普通流式分析

补偿约定为 `measured = true × spillover`，按行向量反解 `true = measured × inverse(spillover)`。矩阵用带主元的 Gauss–Jordan 求逆，奇异矩阵拒绝。单染向导使用各检测器阳性减阴性中位数，再除主检测器中位数差；每个控制群至少 10 事件。光谱解混为普通最小二乘，参考矩阵满秩时求 `Rᵀ(RRᵀ)⁻¹`；没有误差加权、自发荧光模型或自动参考谱修复。

Logicle 为修改双指数的反函数，参数为 T/M/W/A，正负值关于零位置对称。实现独立，基于双指数定义，以二分求参数和反解；不是厂商代码。默认 T=262144、M=4.5、W=.5、A=0，与独立安装的 flowutils 在 −100000 至 1000000 的 11 个基准点逐一比较，通过 1e−9 相对 / 绝对容差；同样检查逆变换。参考 [FlowKit Logicle 文档](https://flowkit.readthedocs.io/en/latest/logicle_transform.html)。这些默认值仅为显示设置，不替代仪器对照。

普通几何门在保存的变换坐标中测试，子群必须属于父群。Boolean 为父群与 AND / OR / NOT 结果的交集。四象限左 / 下边界使用半开区间，分界点不重复计数。聚类、QC、投影选择使用源事件索引门，只属于当前样本，不跨样本复制。

MFI 明确定义为中位数。SD 为 n−1 样本标准差（单事件取 0）；CV 使用 SD / |均值|，均值为零时留空。几何均值仅在全部值为正时计算；空群统计留空。图中隐藏的 Log10 非正事件仍保留在总体数据和统计中。

QC 采用等事件数窗口，每窗口计算事件数 / Time 差和指定参数中位数，分别用全窗口中位数及 MAD × 1.4826 标记离群，尺度下限为 |中位数| × 3% 或 1e−9。时间回退事件和可选的参数上界事件另标记。不是 FlowJo 变点检测，也不自动移除事件。

## 降维、聚类与类别门

选择参数先做 Arcsinh(value / cofactor)，可对训练集做 Z-score，并用相同均值 / SD 处理待分配事件。恒定训练通道拒绝。显式随机种子使用 mulberry32；训练 / 投影事件以 reservoir sampling 无放回抽样，保存排序后的源索引。同一软件版本、输入、种子和参数下可复现；浏览器 / 浮点平台之间不承诺位级相等。

- **UMAP**：随应用离线打包的 [PAIR umap-js](https://github.com/PAIR-code/umap-js)。保留 Apache 2.0 许可；开放 neighbors、minDist、epochs 与 seed。只嵌入抽样事件。
- **t-SNE**：随应用打包的 [Andrej Karpathy tsnejs](https://github.com/karpathy/tsnejs)，上游 README 声明 MIT。唯一功能补丁为注入种子 RNG 并重置 Gaussian 缓存。exact 距离 / 梯度，开放 perplexity / iterations / seed，学习率 10；不是 opt-SNE。上游无单独许可文件，随包记录来源声明与 MIT 文本。
- **SOM + Ward**：独立在线方形 SOM，随机训练行，训练 10 个 epoch，学习率从约 .42 降至 .02，Gaussian 邻域半径从半网格降至 .6；对 codebook 做 Ward 加权层次合并。将全部父群事件映射到最近节点及其元群。Prim MST 保存在结果 JSON。不是官方 FlowSOM 或共识聚类。
- **kNN 密度模式（实验性）**：训练数据全距离 kNN，第 k 近邻平方距离的对数估计相对密度，向邻居中更高密度者链接，确定性处理相等密度；没有更高邻居时形成根。训练事件保留模式标签，其余父群事件按最近模式类中心分配。该推断可能忽略非凸群边缘，**不是 X-Shift**。

聚类表输出全部父群的类别计数、比例及原分析数值的各通道中位数。聚类画布显示训练抽样在前两个预处理参数上的投影，不把它冒充额外 UMAP。UMAP/t-SNE 画布可框选生成“sampled”门，仅包含显示的源事件，不外推类别。算法或当前父群 / 补偿 / 数值不一致时拒绝用旧结果导出或生成新门。

## 周期与增殖模型

两者均只拟合正值事件，排除数和置信度单独输出。用户需要提供来自合适对照的峰位和 CV，模型不自动找生物学峰。

周期密度：G1 为 N(μ, σ)，G2 为 N(2μ, 2σ)，σ=μ×CV/100；S 为 [μ,2μ] 均匀 DNA 含量与 N(0,σ) 卷积。固定这些成分形状，只用 EM 拟合非负和为一的权重，最多 200 次迭代。输出 log likelihood、收敛状态、范围外事件、成分期望数，以及最大后验硬分类。不是 Watson / Dean–Jett–Fox，不支持碎片、聚集和双细胞模型。

增殖先转 log2，G0 均值为 log2(用户峰位)，第 i 代均值减 i；固定 σ=sqrt(ln(1+CV²))/ln(2)，此处 CV 使用比例。EM 拟合代次权重。Ni 为第 i 代拟合事件数，Pi=Ni/2^i 为前体贡献：

- Percent Divided = Σ(i≥1)Pi / ΣPi × 100%。
- Division Index = Σ iPi / ΣPi。
- Proliferation Index = Σ iPi / Σ(i≥1)Pi。
- Expansion Index = ΣNi / ΣPi。
- Replication Index = Σ(i≥1)Ni / Σ(i≥1)Pi。

分母为零时留空，不人为置零。上述指标定义参考 [FlowJo proliferation 文档](https://docs.flowjo.com/flowjo/experiment-based-platforms/proliferation/)，拟合实现独立；期望事件数可以为小数，不能与最大后验门数混为一谈。

## 胶图方法

v1.4 改用旋转坐标中的投影搜索，替代仅对竖直列求和：

1. ROI 按块平均降采样，最大边不超过 420 个检测像素。每行做水平形态学开运算估计局部基线；邻接差的中位数估计噪声，扣除后保留正残差。检测副本的 97% 分位限幅用于减弱强条带；不修改源数据。
2. 搜索 −30° 到 +30°，先每 2° 粗搜，再在最佳角附近每 .25° 细搜。在旋转坐标 u=x cosθ−y sinθ、v=x sinθ+y cosθ 上进行线性权重投票。评分为两个平滑投影平方和按尺寸归一化，横向条带投影权重 .15，泳道投影权重 1，避免不同泳道的条带高度差支配倾角。相对 0° 改善不足 .5% 时保留 0°。手动角度会覆盖搜索。
3. 泳道投影经过按宽度平滑、相对阈值、局部突出度和最小间距筛选。输入的预计数量为上限，不凭空补足空泳道。输出倾角、中心两端和相对峰分数；分数不是概率或可靠性认证。边缘裁短使中心线保留在 ROI 内。
4. 自动泳道采用正交条带坐标。原始像素投影到中心线的垂足，按垂足 Y 分箱，逐像素计入原始积分 / 饱和计数；两侧 5 px 法向环带用于背景。每个像素只分配到一个分箱，不旋转原图、不插值灰度。检测和绘制都使用同一几何；因此条带边界随泳道倾斜。
5. 手动折线中心路径使用最近有效线段投影，像素仍只分配一次；Rf 使用中心线累计长度比例。转折过急、回折和透视变形不在自动模型内，手动路径需从上到下单调。旧项目未启用 orthogonal 的泳道按旧方法复算以保持兼容。

条带用平滑信号定位峰，以相邻差中位数估计噪声并设置 4 倍噪声下限，再做相对阈值 / 宽度 / 间距筛选，最终积分使用未平滑的源数据。相邻条带积分区间避免重叠，人工边界编辑也拒绝重叠。显示旋转不修改原始像素；v1.7.0 新建泳道在当前显示方向定义几何并投影原始像素，已有泳道保持创建时的几何。多通道仍需预先配准。

这不是自动追踪弯曲泳道或透视配准算法。自动方法对边框、反光、单条带、强拖尾及粘连仍可能失效。保留图像中观察到的结构与手工核对入口，不把候选泳道当作正确答案。
背景为侧边 5 像素中位数、指定常量、沿泳道的滚动窗口形态学开运算或下凸包。净积分保留负值，不强制归零；饱和像素按指定满量程计数。MW 使用 log10 标准值对 Rf 的线性回归或分段插值；量标定先缩放积分以改善数值条件，再做低阶最小二乘。范围外默认留空。

Western normalised=target×standardLoading/loading；fold=(target/loading)/(standardTarget/standardLoading)。Spot 以像素中心判断形状内外，局部背景排除邻近斑点，没有可用背景时报错。菌落为 8 邻域连通域，圆度采用格点边界周长；相连分割为 chamfer 距离种子加最近种子划分，并非精确 watershed。

## v1.5.0 三框建泳道与逐泳道 Marker

三个矩形依次代表相邻的首、次泳道以及末泳道；共同高度取三个框的纵向交集，宽度取中位数。把参考框中心按手动整体倾角投影到共同中部高度，首 / 次中心距估计间隔数，四舍五入后若残差超过四分之一间距则拒绝。根据首末中心精确插值，最多 200 条；不检测图像亮暗、不自动补删弱信号泳道。矩形过宽导致重叠、次泳道顺序错误、高度无交集或越界均拒绝。此方法假定平行且等距，不能自动恢复透视或不规则孔间距；允许后续逐条调整中心线。

泳道配置与条带分析分两步。逐泳道删除保留原 ID 并删除该泳道各通道条带，清除受几何影响的标定。每条泳道保存独立 Marker 标准快照，库更新不悄悄改变已选标准。多个 Marker 必须使用一致单位；条带数量与标准不一致时拒绝自动对应，需人工修正或填写。填入对应后仍需核对并明确计算，不自动推断缺失条带的分子量。

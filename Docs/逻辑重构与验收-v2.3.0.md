# 胶个朋友 2.3.0 · 逻辑重构与验收

日期：2026-10-16。版本 2.3.0（25）。旧 2.2.2 安装包与源码归档保留。

## 本轮实施

1. 单项目的已用泳道/条带编号记录随项目保存，删除后不复用。自动检测和整批泳道重建分配新身份；Marker 引用缺失时明确要求重新对应，不依据相同显示序号续接。
2. 当前工作区使用一套泳道选择。回访泳道不撤销确认，实际改变泳道需重新确认。无 Marker 的步骤前进及返回均跳过标定。相对比较和已知量标定提供明确的独立任务出口。
3. 通道分别保存大小模型、量模型、标准编辑和参考选择。旧项目的单套配置迁移到其声明通道；新通道不继承另一通道的量标准。
4. 量标准草稿与已应用规格分开。值、标准条带、回归或单位修改后提示更新，不继续显示旧数量作为当前结果。大小方法修改同样触发更新。
5. 根据标准实际引用处理条带修改：无关样本编辑不清除标准模型；标准点编辑才使相关模型待更新。泳道几何改变处理该泳道各通道的依赖，背景改变处理全局背景设置的依赖。
6. 查看与分析共用通道显示记录，保存黑白点、Gamma、反相；旋转与相机继续沿用已有全局记录。批量从当前 Web 工作区获取显示设置，原始 TIFF 保持原始数据。
7. 项目级撤销/重做覆盖对象编辑、标准配对、设置及检测替换，跨泳道保留。快照不复制原始像素，内存有界；文本输入中的系统撤销保留。重启后不恢复撤销栈，项目保留操作记录。
8. 原生项目路径、修订与保存回执形成闭环；保存更新原文件，另存为保留原文件；关闭、退出、替换检查未保存修改。恢复副本约在最后修改 1.8 秒后写入本机，启动可恢复为未保存项目。单当前项目/单恢复副本，磁盘错误提示用户主动保存。
9. 核对条带可逐泳道标记人工确认，编辑/识别后清除受影响标记。导出使用工作区内弹层，列出可定位的待核对、失效与饱和项；未完成报告带草稿标识和问题记录。

## 自动验证

177 项：原始文件/旋转/批量 35，分析核心 47，倾斜几何 13，工作区 30，流程 32，新增项目逻辑 20。旧检查按新的合法行为更新：不再要求回访撤销确认或切换清除撤销；重建对象不再假定复用 L1/b1。报告生成检查直接测试生成函数，新增检查单独测试导出核对入口。

新增检查复现上一轮审查的七类缺陷并验证修复；另覆盖两个通道标准同时应用、引用错误拒绝、观察参数与像素往返、检测撤销、旧保存回执与新编辑、批量当前设置、核对标记、草稿报告及损坏配置拒绝。组件模拟 Canvas 不代替真实胶图识别准确率或原生验证。

## 原生验证

使用独立 bundle ID 的 QA 副本，只修改初始窗口大小为 1150×708 内容尺寸，避免接触用户的运行应用及恢复记录；合成项目明确标注“非实验数据”。

- 已保存项目打开后显示正确名称、当前 L2、500 bp 示例结果与积分曲线。
- 反相后关闭窗口出现保存/不保存/取消；取消保留分析。Cmd+S 直接更新同一测试项目，读取文件确认反相记录为 true。
- 另存为打开系统保存框，取消保留原项目；退出时选择保存可完成原位写入并退出，恢复副本随后清理。
- 在核对条带页确认 L2，界面显示未保存及已核对；切到 L3 后 Cmd+Z 撤销 L2 的核对，当前 L3 不跳转，重做入口可用。
- 原生实际生成恢复文件，读取确认步骤为 bands、L2 核对标记保留。用该实际文件在独立 QA 目录模拟下次启动，恢复提示可进入原步骤，L2、反相和核对标记保留，显示“恢复的实验 · 未保存”。没有进行强制终止用户应用的测试。
- 导出核对弹层显示待核对数量、可滚动清单和草稿导出按钮；Esc 返回原结果页。测试屏幕截图部分窗口边缘受屏幕范围裁切，未据此宣称所有尺寸布局已完整验收。

## 保留的限制

本轮不替换自动识别算法，不新增跨图像自动配准、批量分析模板或完整模板分组。跨泳道标定仍要求分析几何使用兼容方向；多通道归一化仍需用户核对图像位置。撤销栈只属于本次会话；本机恢复副本不代替主动保存，仍有写入间隔。导出提供现有完整标注图与报告文件组，独立“当前视口截图”等导出格式尚未新增。

# 泳道切换与图文关于 · 2.2.2

日期：2026-10-15。

## 原因与改动

核对条带默认收起参数检查器，旧“当前泳道”和识别按钮都在该检查器内，导致核心功能不可发现。Marker 与样本结果还各自维护一个筛选器，可能使显示对象与实际选中泳道不同。

新增常驻泳道工具栏，以 laneID 为唯一当前泳道，所有工作流步骤同步图像高亮、积分曲线、Marker 和结果。前后切换尊重实际泳道清单，不依赖 ID 连号。参数折叠、专注和查看页不隐藏工具栏。切换保留原始像素与相机记录，取消旧对象的未开始编辑状态。

识别范围显式区分当前泳道、当前通道所有泳道、全部通道所有泳道；默认不会重算其他泳道。人工范围存在时先确认，检测候选成功计算后统一写入，待确认请求在泳道/通道/范围切换后取消。

关于使用本地 HTML dialog，原有胶个朋友胶块插画、简短介绍与版本标识。Swift 菜单发送版本到当前工作区，页面上的弹层不新建工作页面。支持焦点恢复、Esc、关闭按钮、减少动态效果；不改变科学数据、相机或专注状态。

## 验证

组件检查覆盖常驻入口、参数折叠与专注、跨步骤切换、Marker/样本同步、三类识别范围、手工条带替换确认、图像点击与拖动分工、关于开关与 Esc 的数据不变性。原有原始像素、几何、Marker 与三框预览检查继续执行。

共 157 项检查通过：35 原始图像/批量、47 分析核心、13 几何、30 工作区、32 流程。

原生 AppKit / WKWebView 使用仅修改初始窗口尺寸的 QA 副本，在 1150×740 总窗口验证：项目结果页的当前泳道与结果、曲线一致；进入核对条带并收起参数后，泳道切换与自动识别仍可见。点击下一泳道后选择器和曲线同步到 L3，倍率保持 108%；点击当前泳道识别得到 4 条候选条带。图文关于在小窗口内完整显示；分析页打开后按 Esc 关闭，仍留在核对条带、L3、108% 和参数收起状态。该项目为明确标注的合成测试数据，候选数量不代表真实实验识别准确率。

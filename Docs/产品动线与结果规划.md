# 胶个朋友 · 产品动线与结果规划

日期：2026-10-14

状态：总体产品规划。2.2.0 已实施实验类型入口、动态步骤导航、显式 Marker 对应、胶图结果卡片与联动、独立量标准、逐样本 Western 配对、菌落/斑点专属步骤及分类报告。跨图像自动配准、批量分析模板、重复分组、完整的退出未保存处理仍为后续工作；不能将本文全部条目视为已交付。原 2.1.0 分发包及源码归档保留。

## 1. 需要修正的结构问题

当前导航把实验类型（Western、菌落、斑点）、分析步骤（泳道、标定）、资源（Marker 库）放在同一层。用户必须自行寻找入口、判断先后顺序和理解计算条件。

现有 Marker 对应入口要求实际条带数与预设标准数完全一致；计算后标准与样本混在含大量技术参数的表中。标定图仅呈现首个 Marker 模型的回归线，不能完整解释实际使用的分段或多个 Marker 标定。因此需要重做动线与结果表达，不能仅靠重新排按钮解决。

## 2. 统一产品结构

首页提供：新建实验、继续项目、批量任务。Marker 库、使用帮助和偏好设置属于资源入口，不属于分析步骤。

新建实验先选择类型，再选文件。常用类型为核酸电泳、蛋白电泳、Western blot；菌落计数与 Dot/Spot blot 放在“其他实验”中。类型明确后才显示胶图。

- 核酸电泳采用 bp；蛋白电泳与 Western 的大小标定采用 kDa。当前标准库仅支持 bp/kDa，不把 RNA 的 nt 标定冒充现有能力。
- 单通道/多通道属于图像组织方式；多重荧光不再成为独立、平行的导航模块。
- 可只查看，无需完成分析或提供 Marker。实验类型决定后续工具，不强迫用户分析。
- Finder 打开或拖入原图时先暂存文件并选择实验类型，然后显示图像；打开已保存的新项目直接恢复类型和所在步骤。
- 旧项目缺少实验类型时选择一次并保存，不依据文件名猜测。
- 同一项目只承载一个明确的实验流程。分析后改变实验类型时建立项目副本，保留原项目。
- 当前项目显示同次实验的图像/通道清单；不同实验类型的文件不能因“添加通道”被混入同一流程。

主工作区的导航只显示当前实验步骤、完成状态和当前所在位置。上方显示项目名与实验类型，底部提供保存、资源与返回首页。无关实验类型不会出现在当前实验的左栏。

每一步只有一个明确主按钮；已完成步骤可回访，未满足条件时说明具体缺项并提供定位入口。用户可保存未完成项目。

## 3. 核酸/蛋白电泳主流程

| 步骤 | 核心操作 | 完成后去向 |
| --- | --- | --- |
| 1 查看胶图 | 查看文件信息、通道、原始位深与饱和提示；旋转、反相、显示调整、缩放、平移、独立专注模式 | “开始分析”；也可直接保存或导出图像 |
| 2 设置泳道 | 首条、第二条、末条三框生成等距泳道；逐条移动/调尺寸；手动增删泳道；命名样本；指定各 Marker 泳道和标准 | “确认泳道” |
| 3 核对条带 | 识别仅作候选；在胶图和积分曲线上增删、移动、改边界；设置信号方向与背景扣除；查看原始/背景/净积分 | 有 Marker 时“核对 Marker”，否则“查看条带结果” |
| 4 Marker 标定 | 逐个 Marker 泳道核对条带与标准值的对应、确认有效点与范围 | “确认标定并查看结果” |
| 5 查看结果 | 胶图标签、选中条带卡片、简洁样本表、可展开标定质量 | 保存/导出；或按需求进入定量比较 |
| 可选 定量比较 | 相对信号比较或使用独立的已知量标准进行绝对定量 | 返回带有相应定量字段的结果页 |

自动泳道是设置泳道内的可选辅助功能，不作为必经入口。三框方式作为默认。旋转/反相/平移/缩放在所有步骤都可用，同一胶图共用观察状态。

泳道删除不重排样本的稳定身份；显示顺序可更新，但引用、Marker 对应和历史不能因重新编号指向错误对象。

没有 Marker 仍能看图、框泳道、编辑条带、做强度比较和导出；结果明确显示“未进行大小标定”。

### 3.1 Marker 对应关系

每个 Marker 泳道独立选择预设或自建标准，保存所用版本快照。选择器内可新建/编辑个人 Marker，完成后返回原泳道。

对应界面采用胶图、当前 Marker 放大局部和标准值列表联动：点击一条标准值，再点击其实际条带，建立明确配对。已配对项显示共同序号；可取消、重配、标记标准条带缺失，或排除多余实际条带。

软件可提供有明确提示的候选对应，但必须可核对；不能在缺带时按条带顺序自动错位。不存在“必须识别出全部预设条带才能继续”的限制。

匹配点至少满足所选方法的条件。当前方法最低为两个不同位置、正数且顺序合理的有效点；达到最低点数不等于高精度，界面同时显示点数与覆盖区间。饱和、低信噪等问题与用户可采取的动作关联。

DNA 与蛋白标准不得混用于一次大小标定。多个 Marker 显示各自范围和对应关系；默认采用明确的邻近标准策略，高级面板可选平均或横向插值，结果详情记录实际策略与来源。

### 3.2 标定后结果呈现

结果页默认以胶图为主体。侧边详情默认收起或窄显示，底部仅保留可调高度的当前泳道积分曲线。样本汇总表按需展开，不能把胶图挤成缩略图。

胶图仅给当前选择/用户开启显示的样本条带加大小标签，避免把所有技术值铺满。点击任意条带同时定位胶图、曲线和结果行。

当前条带卡片依次给出：样本名、条带名、大小与单位、净积分、状态；存在独立定量标准时再显示数量与单位。Marker 条带默认作为标准层，不与样本结果混排。

默认表：样本、条带、bp 或 kDa、净积分、结果状态。Rf、像素边界、原始积分、背景积分、拟合参数等放入“详细数据”与完整导出。

数值保留位数与方法能力相符，不用大量小数制造精确感。缺失值必须有原因：未标定、匹配不足、超出标定范围、信号饱和或上游修改待更新，不能只有一个横杠。

“检查标定”展示实际所用模型、各 Marker 的匹配点、拟合/插值曲线、覆盖区间与误差/残差信息。R²不能单独代表结果准确性。分段模型按实际分段绘制，不替换为无关回归直线。

默认不对范围外条带给出普通大小值。若用户明确启用外推，结果注明“外推估计”，图像、表格与报告保持一致。模型误差不等于测量不确定度，没有验证时不生成虚假的置信区间。

用户发现异常时可直接从结果卡片返回该条带或 Marker 对应点，不必搜索其他菜单。

### 3.3 定量比较

大小标定回答“多大”；量标准标定回答“多少”。两者是独立步骤与数据对象，不能把 Marker 的 bp/kDa 数值当成 ng。

相对比较：选择参与比较的条带与参考样本/参考条带，显示净积分和相对比例，并记录背景与选择条件。

绝对定量：选择已知数量的标准条带、输入单位与数值、核对标定范围和拟合，再应用到样本。没有标准时不显示绝对数量；样本超出范围明确标记。

泳道内百分比明确写出分母为该泳道所纳入条带净积分之和，不暗示其为真实分子比例。

## 4. Western blot 专属流程

入口：新建实验 → Western blot → 打开图像。

步骤：查看图像 → 设置样本与通道 → 设置泳道 → 核对目标/参照信号 → 归一化 → 查看结果 → 导出。

- 支持同图不同区域、多个通道或目标/内参分别成像的组织方式；跨图像必须明确对应关系并核对配准，不因尺寸相同就假设已对齐。
- 用户给通道/区域分配目标蛋白、内参或总蛋白角色，命名样本和参考样本；技术重复可标记，不自动冒充生物重复。
- 逐样本选择目标带及内参带；总蛋白方式选择明确的积分区域。允许因迁移差异而调整各泳道的范围，不要求用户输入同一套 Y 坐标。
- Marker 为可选的大小注释步骤，可在条带核对后开启；不会把 Marker 当作上样内参，也不作为归一化的强制前提。
- 归一化页展示目标净信号、内参/总蛋白净信号、二者比值、相对参考样本的倍数。提供可展开计算说明，记录所用方式和参考。
- 参照缺失、无效或饱和的样本明确列为待处理，不默默输出貌似正常的倍数。
- 查看结果：胶图定位与样本卡片联动；表和比较图按需展开。重复、误差线等只在用户定义了合理分组后使用。

现有实现使用共同 Y 范围；逐样本配对、跨图像角色与配准核对属于本轮规划的新能力，尚未实施。

## 5. 菌落与 Dot/Spot blot

菌落计数：选实验类型 → 查看图像 → 框培养皿/计数区域 → 检测候选 → 手动增加、删除、纠正连体候选 → 核对总数 → 结果/导出。

结果以计数图和总数为主；筛选条件、排除对象与可选面积指标在详情中。只有明确给出空间标尺后才显示实际面积单位。流程不出现泳道、条带或 Marker。

Dot/Spot blot：选实验类型 → 查看图像 → 手动框斑点或建网格 → 调整单个位置/尺寸 → 指定样本、空白、可选量标准 → 核对背景与净信号 → 相对比较或可选绝对定量 → 结果/导出。

结果为斑点图、样本清单与相对/绝对量；此流程无泳道和大小 Marker。已知量标准与通用定量资源相连，但入口使用当前实验的名称。

## 6. 多通道、批量、资源与导出

多通道：在当前实验的图像清单中命名/分配角色，核对几何关系；各通道保留自己的显示参数与信号方向。叠加仅用于查看，定量仍使用各通道原始像素。未完成配准核对时不复制定量区域到另一图像。

批量首页先分两种任务，避免把批量导出与批量分析混为一谈：

1. 批量图像处理：选类型和文件 → 设置旋转/反相/显示参数 → 预览代表图 → 选输出内容和目录 → 运行 → 逐文件完成清单。保留原始数据并明确显示效果导出与保留数据导出的区别；输出不覆盖源文件。
2. 批量分析：选同实验类型文件 → 使用已核对的模板 → 每图检查泳道/条带/标准对应 → 运行 → 将需人工复核的项目单列 → 汇总报告。模板不会把不同图片上相同像素坐标视为同一个可靠样本；不满足条件的图不纳入正式有效结果。

Marker 库：预设和个人条目、名称、单位、标准值及来源备注；新建/复制/编辑/删除个人条目，导入/导出。修改库不静默改变已有项目使用的标准快照；用户主动替换后提示重新标定。

输出入口始终位于图像外：当前视图/完整图、可选标注图、简洁结果 CSV、完整数据和参数、项目文件、当前实验报告。没有做过的实验类型不产生空表或空报告章节。

保存项目可在任意步骤执行，保存原始数据引用/数据、类型、通道角色、样本、泳道/区域、条带、标准对应、参数、结果状态、历史和视野。重开项目恢复当前步骤与观察位置。

## 7. 返回、更新与状态

- 旋转、反相、Gamma、缩放、平移是观察操作，不能改变原始定量或清空结果。
- 修改泳道/条带几何或背景时，只标记相关的积分与依赖结果“需要更新”；保留匹配意图并指出失效的点，不能悄悄删掉所有模块结果。
- 改 Marker 标准或对应点影响相关大小标定，不删除无关的信号积分/定量标准。
- 改量标准影响相关数量结果；改 Western 参考影响归一化结果。
- 返回已完成步骤保留选择、参数与视野；修改后主按钮变为“更新结果”，清楚列出受影响范围。
- 结果状态为“待设置/待核对/已确认/需要更新”，状态同时用文字呈现。
- 撤销/重做针对数据编辑；未保存离开有明确保存/保留/放弃选择。不会因普通关闭面板丢数据。

## 8. 页面与视觉约束

1. 首页承载实验选择；工作区承载当前实验，资源用弹层/面板承载。
2. 画布常驻；查看、设置、核对、结果切换更换周边操作，尽量不重新加载胶图。
3. 主操作、当前步骤、下一步可见，技术参数逐层展开。
4. 保留已实现的统一相机、可调框、可调曲线、撤销、独立专注模式与旋转圆环。
5. iOS 风格以系统字体、清晰层级、轻透面板、明确胶囊选中态和短反馈呈现。分析对象不做弹跳，缩放与移动直接跟手，遵循减少动态效果。
6. 常见窗口与大屏都以胶图占最大可用区域为验收条件；结果页也不能退化为上面小图、下面大表。

## 9. 实施顺序与验收场景

第一阶段：类型选择、项目类型/兼容迁移、动态步骤导航、去除无关工具入口。先让最常用的核酸/蛋白电泳流程成立。

第二阶段：重做 Marker 对应与标定结果；拆开大小与量标准；修正模型展示与局部依赖更新；保留原有科学算法验证，新增行为验证。

第三阶段：将 Western、菌落、斑点、多通道各自收拢为独立完整动线；批量任务、项目恢复与报告跟随实验类型。

第四阶段：统一空状态、错误定位、键盘/触控反馈、动效与尺寸适配，完成真实样本全流程验证后再发布新版本。

关键验收：

- 未选实验类型不会先显示原图；打开已知类型项目直接恢复。
- 核酸项目左栏不出现 Western、菌落或斑点入口。
- 一张只有部分 Marker 条带的真实胶图可明确配对、排除缺失值并查看样本大小，不强制凑齐标准数。
- 两条不同 Marker 泳道均可核对，结果能解释使用了哪条标准及其范围。
- 点击结果能定位胶图/曲线；范围外、未标定、待更新不混作普通数值。
- 无 Marker 的项目仍可完成看图、条带积分与导出。
- 返回修改条带后，受影响结果有提示，无关数据保留；显示调整不会使定量失效。
- Western 用户不需要输入像素 Y 坐标完成逐样本目标/内参配对。
- 菌落与斑点流程不显示不相关的泳道或 Marker 步骤。
- 报告只包含当前实验，大小与定量标准均可追溯，原始数据保持不变。

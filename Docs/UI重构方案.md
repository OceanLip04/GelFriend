# 胶个朋友 · UI 与交互重构方案

状态：胶个朋友 2.1.0 已按本方案完成窄导航、分段工具、共享视野、曲线高度调节、面板抽屉及动效重构；下文保留实施规格，验收记录见算法与验证文档。

## 产品与代码边界

- 胶个朋友：`sgd_viewer`，独立应用标识 `local.research.gelfriend`。负责 SGD / TIFF / PNG、大图查看、泳道、条带、Marker、定量、Western、菌落、斑点及批量导出。
- 细数生命：`flow_viewer`，独立开发对话。负责 FCS 与流式工作流。源码、资源、构建输出各自独立。
- 原来的合并版分发包继续保留；拆分前源码归档于 `archive/combined-source-v1.9.0.zip`，流式目录也保留拆分前快照。
- 胶图项目格式及原始像素保持兼容；旧项目中的个人 Marker 可随项目打开，另可导入之前导出的 Marker JSON。

## 新界面结构

主界面由三部分组成：窄导航、胶图画布、按需出现的检查器。底部只保留当前泳道的积分曲线。

1. **查看**：打开文件直接显示大图。一行工具栏放导入、视图、旋转圆环、反相和“设置泳道”。文件信息以可展开条显示。进入下一步的按钮始终在图像区域外。
2. **泳道设置**：胶图沿用查看时的方向与视野。三框引导在右侧窄面板内，完成后显示泳道清单，支持删除空泳道和逐条设置 Marker。胶图上的框有清晰的选中轮廓及固定屏幕尺寸的控制点。
3. **条带分析**：胶图占据除一行工具栏、底部曲线之外的可用空间。参数面板默认可收起，结果表通过独立抽屉打开。曲线高度可拖动调整，默认约 160–180 pt；曲线与胶图中的选中条带保持一致。

导航收窄到约 64–72 pt，图标有文字提示，展开时才显示完整名称。Marker 库、批量处理、导出和文件详情作为独立面板，避免同时堆在主画布旁。

专注模式保留一行工具和底部曲线；退出专注始终可见，Esc 返回。页面专注与 macOS 窗口全屏保持独立。

## 统一操作模型

工具采用一个互斥的分段控件：**移动胶图 / 调泳道 / 调条带**。任意时刻只有一个工具高亮。默认进入移动胶图，避免普通查看误改分析框。

- 移动胶图：在整个画布范围拖动，包括图片外的空白。滚轮或捏合围绕鼠标缩放；加减、缩放滑块与“完整胶图 / 泳道视野”作为明确入口。按住空格、中键或 Option 可临时平移，松开恢复原工具。
- 调泳道：单击选中，拖框内部移动；拖控制点调宽、高、端点。缩放与旋转后，控制点仍保持相同的屏幕抓取尺寸。拖动仅预览，松手提交；Esc、指针取消或失焦取消未提交修改。
- 调条带：点击胶图或曲线中的条带选中，拖边界改范围、拖内部移动；曲线空白拖动新增，Delete 删除，撤销恢复。重叠、越界有就地提示，不出现无解释的失败。
- 旋转：圆环指针表示方向，拖动旋转。精确角度仅在“···”中出现；方向键微调、Home 归零。查看、框选及分析共用旋转状态。
- 视图状态：同一胶图共享倍率、平移中心与方向；切换步骤、选泳道、打开参数面板、重算积分均不得擅自把图缩回去。“完整胶图 / 泳道视野”才主动重置取景。
- 撤销分清对象：改框可撤销，改条带可撤销；界面说明即将撤销的对象。调框后重算源像素积分，已有标定需重新计算，原始像素不改变。

## 视觉系统与按钮质感

采用 Apple/iOS 的清爽层次：近白底、石墨灰文字、少量系统蓝。胶图背景维持适合看图的深中性灰；颜色只表达操作与选中，不给胶图加装饰色。

- 工具栏和检查器使用轻透材质、细边框与柔和阴影；胶图和科学曲线保持实底，保证观察与截图一致。
- 主操作按钮使用蓝色填充和明确动词；一屏突出一个下一步操作。普通工具使用浅底或透明按钮，悬停出现轻微高光，按下有明确回弹。
- 互斥工具使用一整组胶囊分段控件，选中项为白色浮起片或蓝色浅底，配合图标与文字。选中状态同时依靠轮廓、字重和指示位置，不能只靠一点颜色变化。
- 图标统一线宽、视觉尺寸与对齐方式。画布工具的可点击区域约 36–40 pt，紧凑外观保留充足命中区域；控制点视觉约 8–10 pt，命中区域约 18–22 pt。
- 字体使用系统字体，标题、工具文字、辅助文字分级；技术参数放在详情中，避免原始坐标和算法名占据主要操作区。
- 危险操作与普通操作区分，删除保持明确文字；禁用按钮解释缺少的前置条件。避免所有按钮同时有边框、灰底和阴影。

## iOS 风格动效规格

动效服务于反馈与层级变化，不让正在测量的图像延迟跟手。

| 交互 | 反馈 | 建议时长 |
| --- | --- | --- |
| 按钮按下 / 松开 | 轻微压缩至约 0.97，再恢复，阴影同步减弱 | 80–140 ms |
| 工具切换 | 胶囊选中片平滑移动，文字和图标同时更新 | 180–240 ms |
| 面板 / 抽屉展开 | 小幅位移与淡入，保留当前胶图的观察中心 | 180–260 ms |
| 查看 → 泳道 → 条带 | 同一胶图持续存在，工具区与曲线渐变切换 | 180–240 ms |
| 框选与选中 | 轮廓立即出现，控制点轻微淡入 | 80–120 ms |
| 撤销与完成 | 简短、轻量的状态反馈，提示不遮挡胶图 | 120–180 ms |
| 缩放、平移、拖框、旋转 | 直接跟手，按帧合并绘制，无额外补间或弹跳 | 即时 |

系统开启“减少动态效果”时，关闭位移和弹性，仅保留即时状态变化或短淡入。科学数据、积分值和坐标轴不做跳动、滚动数字或弹性动画。

## 实施顺序与验收

**第一轮：交互与画布。** 统一相机状态和指针路由；覆盖空白拖动、缩放锚点、越界、取消、跨步骤视野继承。验收标准：拖动不抢工具，松手不跳图，旋转后的框与像素一致，源数据不变。

**第二轮：完整布局与组件。** 重排导航、工具栏、检查器、曲线和结果抽屉；集中定义颜色、字体、间距、圆角、阴影与按钮组件。用 1150×740、1420×960 和大屏窗口验收，除必要工具与曲线外，剩余空间全部给胶图。

**第三轮：动效与打磨。** 加入分段指示片、按钮反馈、面板和页面过渡；验收键盘、焦点、减少动态效果和滚动缩放性能。用真实胶图完成“查看 → 三框 → 调框 → Marker → 改条带 → 保存重开”的完整操作，再打包。

完成标准是两份独立可运行的软件，以及胶图主流程操作和视觉验收通过；单纯换色、加圆角不算 UI 重构完成。

# 胶个朋友 2.4.0

独立的胶图查看与分析应用。运行环境为 Apple 芯片 Mac、macOS 13 或更新版本。打开 `dist/GelFriend-v2.4.0.app`；分发包为 `dist/GelFriend-v2.4.0-Mac.zip`。运行无需 Python、Node 或网络。采用本地临时签名，未做 Apple 开发者公证。

流式分析已拆到独立的“细数生命”应用与开发目录；本应用不包含 FCS 导入和流式算法。旧的合并版安装包和源码归档仍保留。

## 2.4.0 本机 Agent 接口

可从 **Agent → 开启本机 Agent 接口** 允许同一用户的本机 Agent 操作当前工作区；默认关闭，随时可关。内置 MCP stdio 与命令行工具，共 28 个接口，支持胶图预览、文件打开/保存、旋转反相、泳道编辑、条带识别与编辑、Marker/已知量标定、Western 归一化、数值曲线读取、撤销及报告导出。

每次修改须提供新读取的文档与上下文版本；你在界面改变通道、泳道、步骤或数据后，旧指令会被拒绝。重识别手工条带、替换未保存文档与覆盖既有输出需明确指定，Agent 不能把候选标为人工核对。开启后仅当前本机用户进程可访问，不开放网络端口。

完整接入说明见 [Agent 接口文档](Docs/Agent接口-v2.4.0.md)，配置示例在 `Agent/mcp.example.json`，精确参数在 `Agent/api.json`。应用内同样保留这些文件。客户端需要支持本机 MCP 进程；不代表云端 ChatGPT 已自动连接。197 项自动检查及隔离原生应用的 39 项接口验收通过，范围见 [Agent 接口验收](Docs/Agent接口验收-v2.4.0.md)。

## 2.3.0 项目与分析逻辑重构

- 返回泳道页只查看时保留确认状态，实际改框才要求重新确认。无 Marker 的实验可直接从结果返回条带核对。相对比较与已知量标定有独立任务入口和完成按钮。
- 泳道、条带的已使用编号不再分配给新对象。删除或重新识别后，旧标准对应会要求重新核对，不能自动绑定到另一条带。
- 大小及量标准按通道独立保存。量标准输入与已应用版本分开，修改后清除相关旧数量显示并提示更新；样本条带编辑保留不依赖它的标准模型。修改标准、信号或背景时更新相关依赖。
- 反相、黑白点、Gamma 按通道保存；查看与分析共用。显示参数不改变原始像素或积分。批量“沿用当前胶图”读取当前工作区的参数；原始 TIFF 仍保留原始像素和方向。
- 项目级撤销/重做可跨泳道、跨步骤使用，包含手工编辑、标准对应及识别替换。Cmd+Z / Shift+Cmd+Z；输入框内保留文本编辑的撤销。历史保留当前会话最多 40 次、约 8 MiB 字符存储，重启后保留操作记录而不恢复撤销栈。
- Cmd+S 更新原项目；Shift+Cmd+S 另存为。关闭、退出、替换实验时有保存/不保存/取消。保存回执按修订号处理，不会把之后的编辑误标为已保存。
- 未保存修改停止约 1.8 秒后写入本机恢复副本；启动时可恢复，恢复后另存为。恢复副本属于当前应用、不是原始文件，也不代替主动保存；磁盘写入失败会提示保存。仅支持一个当前项目及一份恢复副本。
- 核对条带新增“本泳道已核对”，区别自动候选和人工确认；编辑或重识别会取消相关核对标记。导出先显示可定位的问题清单，未核对/待更新内容标为草稿，报告和参数记录携带状态。没有 Marker 仍可导出积分结果。

本版沿用已有识别与原始像素积分算法，重点修复对象、通道、步骤和结果依赖。未新增跨图像自动配准或批量分析模板。旧项目继续支持，个人标准库保留。177 项自动检查及原生保存、关闭、另存为、撤销、恢复操作验证见《逻辑重构与验收-v2.3.0》。

## 2.2.2 常驻泳道切换与图文关于

“当前泳道”移到常驻工具栏，提供下拉选择与前后切换。查看、泳道设置、核对条带、Marker、结果、定量及 Western 共用同一个当前泳道。收起参数或进入专注后入口保留，图像选中、曲线和结果同步，切换不重置视野。

核对条带页常驻“自动识别条带”，默认识别当前泳道；也可明确选择当前通道全部泳道或全部通道全部泳道。“识别参数”展开原参数面板。识别范围内存在人工条带时先确认替换，取消保留原数据；切换泳道会取消待确认请求。

Marker 页面可切到样本查看曲线，但只有已指定的标准泳道显示对应列表。结果页也可查看 Marker，不再被样本筛选器强行跳回另一泳道。移动模式下点击胶内泳道可选中，拖动仍用于平移。

“关于胶个朋友”改为当前页面上的图文弹层，保留原来的胶块插画，展示短诗、用途和实际版本号。继续、关闭按钮或 Esc 返回原页面并恢复焦点；不会唤出旧查看窗口，也不会退出专注模式。

## 2.2.1 三框泳道与“关于”修复

旧版把首末距离与前两框间距之比偏离整数超过 0.25 视为错误，普通手画误差也会触发“末泳道与前两个的间距不一致”。本版去掉该拦截：前两个框只用于估算数量，首末框固定位置，内部泳道均匀排列。

三框完成后立即显示青色虚线预览。“泳道总数”留空自动估算，可直接输入实际数量或点加减。预览不改变已有泳道、Marker 或条带；点击“使用这 N 条泳道”才替换。框偏宽时自动收窄避免重叠，并提示原因。生成后仍可逐条拖动、调宽、删除空泳道。

“关于胶个朋友”只在当前工作区显示版本弹窗，不再唤起隐藏的旧查看窗口；关闭后保留当前页面与视野。

## 实验流程

- 先选核酸电泳、蛋白电泳、Western blot、菌落计数或 Dot/Spot blot，再显示图像。Finder 打开的原图先选择类型；已有项目恢复自己的类型与步骤，旧项目选择一次类型。
- 左栏只显示当前实验步骤。Marker 库通过资源面板打开，返回时回到原步骤；Western 不再作为每张胶图的公共侧栏入口。
- 核酸/蛋白：查看 → 泳道 → 条带 → 可选 Marker → 结果。无 Marker 时可直接查看净积分结果。
- Marker 在图像/曲线与标准列表之间显式配对，允许缺失标准带，允许排除多余实际带；每条参与的标准泳道至少需要两个有效对应点。条带数不必与预设一致。
- 结果保留大胶图和底部曲线。点击条带或结果行同步定位；详情显示大小、净积分与状态，技术表按需展开。质量面板显示实际分段/对数模型、各标准泳道与覆盖范围；范围外默认不外推。
- 大小与含量使用独立标准；定量比较可选择参考条带，也可填写独立已知量标准。
- Western 按样本选择实际目标与内参条带，或使用整个泳道总蛋白；多通道归一化前须核对位置。参考样本与饱和信号有明确检查。
- 菌落和斑点各自有区域设置、核对及结果步骤，不显示泳道或 Marker。
- 显示旋转、反相、缩放和平移不使标定失效。修改数据时保留标准对应，标记相关结果需要更新；改 Marker 不清除独立量标准。
- 报告按实验类型组织，不生成无关空章节。项目继续保存原始像素、标准快照、历史、实验类型、当前步骤和视野。

实验卡片有轻抬起与按压反馈；工具胶囊有滑动选中片；步骤切换仅轻淡入操作面板；Marker 配对使用对应高亮与短光晕；结果抽屉轻滑入。所有动效不改变图像位置或测量坐标。系统减少动态效果时关闭位移、弹性和补间。

本轮没有新增跨图像自动配准或批量分析模板。多通道仍需事先对齐；批量入口用于已有的图像旋转、显示调整与导出。

## 打开与查看

“打开”支持 SGD、8/16 位灰度或 RGB TIFF / PNG。多页 TIFF 和 RGB 图像可拆成通道；同一项目的通道必须尺寸一致，并事先配准。

查看页先显示格式、尺寸、位深、通道数、灰度范围和满量程比例；“信息”展开采集记录、文件大小和校验信息。滚轮围绕鼠标缩放，拖动移动图像。“完整 / 铺满”、1:1、加减按钮和缩放滑块提供明确的取景入口。“画面”可调整对比度和 Gamma，反相在主工具栏直接可用。

选择实验类型后打开图像，点击图像外的“开始分析”进入该实验步骤。保存和导出在查看时也可使用。

## 泳道与 Marker

1. 在参考泳道面板点击“开始框选”，依次框住第一个、相邻第二个、最后一个泳道的完整分析高度，查看虚线预览，数量不对可直接改“泳道总数”，再点击“使用这 N 条泳道”。数量默认按前两个间距估算，位置对齐首末。
2. 从列表逐条删除空泳道；每条泳道可单独选择内置或个人 Marker。Marker 标准值快照随项目保存。
3. 选择“泳道”工具后，拖框内部移动；拖控制点改宽度、高度或端点。缩放后控制点仍保持固定屏幕尺寸。松手提交并重算，Esc 或指针取消丢弃未提交修改；“撤销调框”恢复。
4. 确认后进入条带分析。弯曲泳道可在“工具”中选择中心线，逐点点击，双击结束。

移动整个泳道时条带范围随泳道移动；缩短高度时裁到新范围，范围外条带移除。调框保留泳道编号和 Marker，并标记受影响的标定和归一化需要更新；标准对应记录保留。

## 移动胶图与编辑条带

默认工具为“移动”，整个胶图区域包括周围空白都能拖动。按住空格、Option 或使用中键可在调框时临时平移。加减、滚轮和缩放滑块均可缩放。

条带可自动检测后人工核对，也可完全手动建立：

- 在积分曲线空白处横向拖动框住峰，新增条带；也可点击“新增”后拖动。
- 点击条带区域选中，拖左右边界改范围，拖内部移动。删除按钮或曲线聚焦时按 Delete 删除；撤销按钮或 Command-Z 撤销曲线编辑。
- 选择“条带”工具后，可直接在胶图上拖条带框、调整上下控制点；胶图与曲线的选择同步。
- 重叠范围拒绝提交。所有修改均使用原始像素重新积分，保留手动标记和操作记录。

“结果”打开表格抽屉，右上角可关闭。原始积分、背景积分、净积分、Rf、面积和饱和像素均保留；曲线按实际尺寸与屏幕密度绘制，避免横向拉扁文字和线条。

## 定量及其他分析

支持泳道侧边、滚动窗口、下凸包、常量及不扣背景。分子量 / bp 标定支持手动标准、逐泳道 Marker、多标准泳道组合、log 线性及分段插值。标准值与实际条带逐项核对；未出现的标准值可排除。DNA 和蛋白单位不能混在同一次标定中。默认不外推。

含量标定需要已知含量，支持线性、过原点、二次回归。Western 支持逐样本选择目标/内参条带或全泳道总蛋白归一化。菌落、Spot blot 可自动生成候选区域并人工修正。饱和、零内参、负净积分等需人工审阅。独立研究辅助算法尚未与 GeneTools 做一致性验证。

## 保存、报告与批量

“保存”生成 `.gelproject`，包含源像素、标注、Marker 快照、分析参数、旋转和视野；重新打开会校验像素并重算。兼容旧胶图项目；旧项目没有视野信息时按完整图打开。个人 Marker 可从旧项目恢复或导入已有 JSON 库。

“导出”生成 HTML 报告、CSV 和参数结果 JSON，包含标注快照及源文件校验信息。

“更多 → 批量处理与导出”选择多个 SGD，可同时导出 PNG 与原始 16 位 TIFF，保留逐文件结果。PNG 应用批处理面板中的显示与旋转设置；原始 TIFF 保留采集方向和像素值。

## 数据与开发

对比度、反相、旋转、显示缩放均不改变源像素。旋转后的泳道保存创建方向的几何；之后再旋转显示，测量区域保持一致。跨泳道 MW 标定及 Western 统一区间要求泳道在同一方向创建。

最多 8 通道、合计 4000 万像素；单通道最多 2000 万像素。菌落分割区域上限 400 万像素。

`./build.command` 构建独立应用；`./test-analysis.command` 运行 SGD / 旋转 / 批量、胶图数值、倾斜几何和界面组件检查。界面重构记录见 `Docs/UI重构方案.md`，数值方法见 `Docs/算法与验证.md`。
